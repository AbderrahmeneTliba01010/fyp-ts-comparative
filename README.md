# fyp-ts-comparative — comparative analysis of LLM-era time-series forecasters

One harness, one protocol, one test set for the methods in the literature-review deck:
**Informer · Autoformer · FEDformer · PatchTST · LLMTime · GPT4TS · Time-LLM · Chronos · TimesFM · Moirai · MOMENT · Sundial**
+ Tan et al. ablations (`tan_*`), a random-GPT-2 control, and statistical baselines. Primary benchmark: **TIME** (ICML 2026, leakage-controlled).

## Start here
```bash
pip install -e . && pip install -r requirements.txt && pytest -q      # harness check, CPU, 10 s
python scripts/run_model.py --tier smoke --models seasonal_naive naive seasonal_avg drift
```
Then open the notebooks in order:

| Notebook | Purpose |
|---|---|
| `00_environment_and_smoke_test` | install, smoke tier, per-model sanity check on your GPU |
| `01_data_and_protocol` | TIME download, stratified core-task selection, leakage assertions, leaderboard cross-check, contamination ledger |
| `02_run_experiments` | resumable runs by block (statistical → zero-shot → LLMTime → supervised → ablations) |
| `03_analysis_and_figures` | main table, bootstrap CIs, CD diagram, group heatmaps, RQ2/RQ3, contamination robustness → `paper/` |
| `04_mechanism_probes` | curvature-regime error, context sensitivity, patch-size sweep (bridge to our method) |

Read `docs/PROTOCOL.md` (the contract, RQs, fairness rules, deviations), `docs/PLAN.md` (steps + decisions for the professor), `docs/MODEL_NOTES.md` (what breaks first).

## What is verified, and what is not
* **Tested here (pytest + executed notebooks on synthetic data):** task/split logic, metrics (hand-computed cases), runner (resume, failure handling, seasonal-naive fallback), aggregation (relative GM, bootstrap CI, ranks, win rate, Friedman/Nemenyi), plots, LLMTime codec, notebooks 00/01/03/04 end-to-end.
* **Written but NOT executed (no GPU / HF access in the authoring sandbox):** every model wrapper (Chronos, TimesFM, Moirai, MOMENT, Sundial, LLMTime generation, NeuralForecast models, GPT4TS/Time-LLM torch code) and the real-data path of `TimeBenchSource` (written against the `timebench` source). Expect small API fixes — `scripts/check_models.py` finds them in minutes; see `docs/MODEL_NOTES.md`.
* **Numbers in the paper:** none yet. `paper/main.tex` is a skeleton with `\todo{}` markers; tables/figures are generated by notebook 03.

## Adding our own method later
Subclass `Forecaster` (`fit`, `predict` → `Forecast(point, quantiles)`), add one line to `models/registry.py` → it appears in every table, figure and test with no other change.

## Practical tips
Use one conda env per model stack (`requirements-models.txt`), all writing to the same `results/`. Run long blocks under `tmux`. Commit `configs/tasks_core.yaml`: it is part of the protocol.
